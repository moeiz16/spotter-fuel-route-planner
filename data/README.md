# Data files

`fuel-prices-for-be-assessment.csv`
: The fuel price list supplied with the assignment, unmodified.

`geonames-us-postal-codes.txt`
: US postal codes with place name, state, county and coordinates, from
  [GeoNames](https://download.geonames.org/export/zip/) (`US.zip`), licensed
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Used to give each
  town a coordinate. Tab separated, no header; the column layout is described in
  the GeoNames readme at the link above.
